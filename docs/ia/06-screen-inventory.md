# 6. 画面インベントリ（IA レビュー用）

この資料は、情報設計レビューで「IA と画面レイアウトが一致しているか」を確認するためのワイヤーフレームです。色、余白、コンポーネントの見た目を決めるものではありません。

## 表示ラベルの規則

| 面                   | 表示                                  | 理由                             |
| -------------------- | ------------------------------------- | -------------------------------- |
| サイドバーのツリー   | 末尾セグメント（ページ名）            | 親ディレクトリが階層の文脈になる |
| サイドバーの Recent  | フルパス                              | フラットな一覧では親の文脈がない |
| すべてのページの一覧 | フルパス                              | 同名の葉を区別する               |
| ディレクトリの一覧   | フルパス                              | 同名の葉を区別する               |
| 検索結果             | フルパス                              | 同名の葉を区別する               |
| ゴミ箱               | フルパス                              | 同名の葉を区別する               |
| ページヘッダー       | ページ名（末尾セグメント） + パンくず | ページ内ではパンくずが文脈になる |
| パス入力の候補       | フルパス + `/`                        | ディレクトリを選択するため       |

## グローバルシェル

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  メインコンテンツ                               │
│ ・a/b/ページ A    │                                                 │
│ ・c/ページ B      │                                                 │
│                  │                                                 │
│ すべてのページ    │                                                 │
│ ▾ ディレクトリ A  │                                                 │
│   ▸ ディレクトリ B│                                                 │
│   ・ページ C      │                                                 │
│ ・ページ D        │                                                 │
│                  │                                                 │
│ ゴミ箱            │                                                 │
└──────────────────┴─────────────────────────────────────────────────┘
```

- グローバルヘッダー: ブランド、サイドバー開閉、検索、新規ページ、アカウント。
- サイドバー: 最近見たページ、すべてのページのツリー、ゴミ箱。
- メイン: 現在のビュー。
- ページのパンくず、ページ名、ページ操作はグローバルヘッダーに置かない。

## すべてのページ（`/`）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  すべてのページ                  [更新順 ▾]      │
│ ・a/b/ページ A    │  12 ページ                                      │
│ ・c/ページ B      │                                                 │
│                  │  ┌───────────────────────────────────────────┐  │
│ すべてのページ    │  │ a/b/ページ C                              │  │
│ ▾ ディレクトリ A  │  │ 抜粋...                                   │  │
│   ▸ ディレクトリ B│  │ 更新者・更新日時                          │  │
│   ・ページ C      │  └───────────────────────────────────────────┘  │
│ ・ページ D        │  ┌───────────────────────────────────────────┐  │
│                  │  │ c/ページ D                                │  │
│ ゴミ箱            │  │ 抜粋...                                   │  │
│                  │  └───────────────────────────────────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- 本文はフルパス付きの一覧。階層はサイドバーのツリーで辿る。
- 並び順は更新順を既定とし、作成順 / 名前順を選べる。
- 今日 / 昨日などの日付グループは UI 契約で扱う。IA では一覧の順序だけを決める。
- 検索クエリがある場合は、この画面の検索結果ビューになる。
- ディレクトリ指定がある場合は、この画面のディレクトリビューになる。

## ディレクトリ（`/?dir=a/b`）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  すべてのページ / a / b                         │
│ ...              │  b                                              │
│                  │  配下のページ 5 件                              │
│ すべてのページ    │                                                 │
│ ▾ a              │  子ディレクトリ                                 │
│   ▾ b            │  ・a/b/c  →                                     │
│     ・ページ C    │  ・a/b/d  →                                     │
│     ・ページ E    │                                                 │
│ ゴミ箱            │  ┌───────────────────────────────────────────┐  │
│                  │  │ a/b/ページ C                              │  │
│                  │  │ a/b/ページ E                              │  │
│                  │  └───────────────────────────────────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- 本文は一覧。子ディレクトリは一覧上部のリンクで辿る。本文にツリーを二重に表示しない。
- パンくずはこのビューの先頭に置く。ページヘッダーとは別。
- `+` を押すと、初期値（入力途中の prefix）が `a/b/` になる。
- ディレクトリ自身の rename、空ディレクトリ作成は出さない。

## ページ（閲覧、`/pages/:id`）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  すべてのページ / a / b / ページ C               │
│ ・a/b/ページ C    │  ページ C   [保存済み] [編集] [目次] [履歴] [⋯] │
│ ・c/ページ A      │                                                 │
│                  │  ┌──────────────────────────┐  ┌─────────────┐  │
│ すべてのページ    │  │ 本文                     │  │ 目次        │  │
│ ▾ a              │  │                          │  │ ・見出し 1  │  │
│   ▾ b            │  │                          │  │ ・見出し 2  │  │
│     ・ページ C    │  │                          │  │             │  │
│     ・ページ D    │  │                          │  │ バックリンク│  │
│ ゴミ箱            │  └──────────────────────────┘  └─────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- パンくず、ページ名、ページ操作をページヘッダーにまとめる。
- 目次とバックリンクは同じサイドパネル。
- 履歴は閲覧/編集の両方から開ける。開くと右側の補助パネルが履歴に切り替わる（排他）。
- ページメニュー `[⋯]` に削除を置く。
- 未作成の Wiki リンクは、その場から新規ページを作る導線になる。
- ページ内の Wiki リンク、目次アンカー、バックリンクは同じタブで移動する。

## ページ（編集、`/pages/:id` のモード）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  すべてのページ / a / b / ページ C               │
│ ...              │  [a/b/ページ C                ] [保存済み] [閲覧] [履歴] │
│                  │                                                 │
│ すべてのページ    │  ┌───────────────────────────────────────────┐  │
│ ▾ a              │  │ Markdown エディタ                         │  │
│   ▾ b            │  │                                           │  │
│     ・ページ C    │  │                                           │  │
│ ゴミ箱            │  └───────────────────────────────────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- パス入力はフルパス。フォーカスを外すか Enter で保存。
- 本文は自動保存。手動の版保存は、編集モードでも開ける履歴パネルから行う。
- 編集モードでは目次/バックリンクのサイドパネルを出さない。履歴パネルは開ける。
- パス変更後は、サイドバー、パンくず、検索結果の表示を更新する。

## ゴミ箱（`/trash`）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  ゴミ箱                                         │
│ ...              │  削除済みのページ 3 件                          │
│                  │                                                 │
│ すべてのページ    │  ┌───────────────────────────────────────────┐  │
│ ...              │  │ a/b/ページ C                              │  │
│ ゴミ箱            │  │ 削除日時・更新者                          │  │
│                  │  │                    [復元] [完全に削除]    │  │
│                  │  └───────────────────────────────────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- 削除済み Page はフルパスで表示する。
- 復元に失敗した場合は、同じ画面に理由を表示する。
- 完全に削除は確認ダイアログを挟む。
- 削除後はゴミ箱へ移動し、復元できることを見せる。

## 検索パレット（入力あり、オーバーレイ）

```text
┌──────────────────────────────────────────────────────┐
│ 🔍 [ 設計                                      ] Esc  │
├──────────────────────────────────────────────────────┤
│ 検索結果 3 件（上位 5 件を表示）                     │
│ ・a/b/設計メモ                                       │
│   a/b / 設計方針の抜粋...                            │
│ ・c/設計ログ                                         │
│   c / 実装ログの抜粋...                              │
│                                                      │
│ すべての結果を見る                                   │
└──────────────────────────────────────────────────────┘
```

- 入力が空なら Recent を表示。入力があれば上位 5 件を表示する。
- パレットの結果はフルパスと抜粋を表示する。
- 検索結果が 0 件のときは、クエリを初期値にした新規ページ導線を出す。
- 「すべての結果を見る」で `/?q=` の検索結果ビューへ。
- パレットは全画面から開ける。開いた画面の上に重ねる。
- `q` と `dir` が同時にある場合は `q` を優先する。

## 履歴パネル

```text
┌──────────────────────────────┐
│ 履歴                    [×]  │
│ ┌──────────────────────────┐ │
│ │ 現在の版を保存           │ │
│ └──────────────────────────┘ │
│ v3  手動  2026-11-04 10:00   │
│     作成者: alice  [差分を見る] │
│ v2  自動  2026-11-04 09:00   │

│ v1  手動  2026-11-03 18:00   │
│     作成者: alice  [差分を見る] │

```

- 履歴は Page の補助パネル。独立した画面にしない。
- 閲覧/編集の両方から開ける。

- 版を選ぶと版プレビューを開く。直接復元しない。
- 「現在の版を保存」は手動 Revision を作る。

## モバイル（抜粋）

この資料はデスクトップの主要ビューとモバイルの抜粋を示す。全モバイル画面のシート構成・ブレークポイント・初期状態は UI 契約で決める。


- モバイルでも `+` は常設。検索はアイコンで残す。

## レイアウトのルール

1. グローバルヘッダーには、ブランド、検索、新規ページ、アカウントだけを置く。
2. ページのパンくず、ページ名、操作はページヘッダーに置く。
3. サイドバーはページ階層のナビゲーション。本文の一覧とは役割を分ける。
4. すべてのページとディレクトリの本文は一覧。階層はサイドバーのツリーとパンくずで辿る。
5. ページの補助情報は右側のサイドパネルにまとめる。目次とバックリンクは同じパネル。
6. 履歴は閲覧/編集の両方から開け、ページサイドパネルと排他にする。
7. 検索、新規ページ、削除確認、版プレビューはオーバーレイ。ページ遷移の一部にしない。
8. モバイルでも `+` は常設。サイドバーはオーバーレイで開く。
9. ページ遷移時にサイドバーや本文を開閉するアニメーションをしない（UI 契約で決める）。
10. 初期サイドバー状態は UI 契約で決める。この IA では「デスクトップは開、モバイルは閉」を推奨。
11. 目次、履歴、検索の開閉は State として扱い、開時と閉時で別のナビゲーションを作らない。
