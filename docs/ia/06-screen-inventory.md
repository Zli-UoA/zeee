# 6. 画面インベントリ（IA レビュー用）

この資料は、情報設計レビューで「IA と画面レイアウトが一致しているか」を確認するためのワイヤーフレームです。色、余白、コンポーネントの見た目を決めるものではありません。

## グローバルシェル

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  メインコンテンツ                               │
│ ・ページ A        │                                                 │
│ ・ページ B        │                                                 │
│                  │                                                 │
│ すべてのページ    │                                                 │
│ ▾ ディレクトリ A  │                                                 │
│   ▸ ディレクトリ B│                                                 │
│   ・ページ C      │                                                 │
│ ・ページ D        │                                                 │
│                  │                                                 │
│ ゴミ箱            │                                                 │
└──────────────────┴─────────────────────────────────────────────────┘
```

- グローバルヘッダー: ブランド、サイドバー開閉、検索、新規ページ、アカウント。
- サイドバー: 最近見たページ、すべてのページのツリー、ゴミ箱。
- メイン: 現在のビュー。
- ページのパンくず、タイトル、ページ操作はグローバルヘッダーに置かない。

## すべてのページ（`/`）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  すべてのページ                         [並び順] │
│ ・ページ A        │  12 ページ                                      │
│ ・ページ B        │                                                 │
│                  │  今日                                           │
│ すべてのページ    │  ┌───────────────────────────────────────────┐  │
│ ▾ ディレクトリ A  │  │ ページ C                                  │  │
│   ▸ ディレクトリ B│  │ 抜粋...                                   │  │
│   ・ページ C      │  │ 更新者・更新日時                          │  │
│ ・ページ D        │  └───────────────────────────────────────────┘  │
│                  │  昨日                                           │
│ ゴミ箱            │  ...                                            │
└──────────────────┴─────────────────────────────────────────────────┘
```

- 本文側は更新順の一覧。階層はサイドバーのツリーで辿る。
- 検索クエリがある場合は、この画面の検索結果ビューになる。
- ディレクトリ指定がある場合は、この画面のディレクトリビューになる。

## ディレクトリ（`/?dir=a/b`）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  すべてのページ / a / b                         │
│ ...              │  b                                              │
│                  │  配下のページ 5 件                              │
│ すべてのページ    │                                                 │
│ ▾ a              │  ┌───────────────────────────────────────────┐  │
│   ▾ b            │  │ ▾ c                                       │  │
│     ・ページ C    │  │   ・ページ D                              │  │
│     ・ページ E    │  │   ・ページ E                              │  │
│ ゴミ箱            │  └───────────────────────────────────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- パンくずはページヘッダーではなく、このビューの先頭に置く。
- `+` を押すと、初期パスが `a/b/` になる。
- ディレクトリ自身の rename、空ディレクトリ作成は出さない。

## ページ（閲覧、`/pages/:id`）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  すべてのページ / a / b / ページ C               │
│ ・ページ C        │  ページ C        [保存済み] [編集] [目次] [履歴] │
│ ・ページ A        │                                                 │
│                  │  ┌──────────────────────────┐  ┌─────────────┐  │
│ すべてのページ    │  │ 本文                     │  │ 目次        │  │
│ ▾ a              │  │                          │  │ ・見出し 1  │  │
│   ▾ b            │  │                          │  │ ・見出し 2  │  │
│     ・ページ C    │  │                          │  │             │  │
│     ・ページ D    │  │                          │  │ バックリンク│  │
│ ゴミ箱            │  └──────────────────────────┘  └─────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- パンくず、タイトル、ページ操作をページヘッダーにまとめる。
- 目次とバックリンクは同じサイドパネル。
- 履歴を開くと、右側の補助パネルが履歴に切り替わる（排他）。
- ページ内の Wiki リンク、目次アンカー、バックリンクは同じタブで移動する。

## ページ（編集、`/pages/:id` のモード）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  すべてのページ / a / b / ページ C               │
│ ...              │  [a/b/ページ C                ] [保存済み] [閲覧]│
│                  │                                                 │
│ すべてのページ    │  ┌───────────────────────────────────────────┐  │
│ ▾ a              │  │ Markdown エディタ                         │  │
│   ▾ b            │  │                                           │  │
│     ・ページ C    │  │                                           │  │
│ ゴミ箱            │  └───────────────────────────────────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- タイトルはフルパスの入力。フォーカスを外すか Enter で保存。
- 本文は自動保存。手動の版保存は履歴パネルから行う。
- 編集モードでは目次/バックリンクのサイドパネルを出さない。
- パス変更後は、サイドバー、パンくず、検索結果の表示を更新する。

## ゴミ箱（`/trash`）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Zeee   [☰]   [ 検索  ⌘K ]                         [+ 新規]  [◯]   │
├──────────────────┬─────────────────────────────────────────────────┤
│ 最近見たページ    │  ゴミ箱                                         │
│ ...              │  削除済みのページ 3 件                          │
│                  │                                                 │
│ すべてのページ    │  ┌───────────────────────────────────────────┐  │
│ ...              │  │ ページ C                                  │  │
│ ゴミ箱            │  │ 削除日時・更新者                          │  │
│                  │  │                    [復元] [完全に削除]    │  │
│                  │  └───────────────────────────────────────────┘  │
└──────────────────┴─────────────────────────────────────────────────┘
```

- 復元に失敗した場合は、同じ画面に理由を表示する。
- 完全に削除は確認ダイアログを挟む。
- 削除後はゴミ箱へ移動し、復元できることを見せる。

## 検索パレット（オーバーレイ）

```text
┌──────────────────────────────────────────────────────┐
│ 🔍 [ ページを検索                            ] Esc  │
├──────────────────────────────────────────────────────┤
│ 最近見たページ                                       │
│ ・ページ C                                           │
│ ・ページ A                                           │
│                                                      │
│ 検索結果                                             │
│ ・ページ D                                           │
│   パス / 抜粋                                        │
│                                                      │
│ すべての結果を見る                                   │
└──────────────────────────────────────────────────────┘
```

- 入力が空なら Recent を表示。
- 入力があれば検索結果を表示。直接 Page を開ける。
- 「すべての結果を見る」で `/?q=` の検索結果ビューへ。
- パレットは全画面から開ける。開いた画面の上に重ねる。

## 新規ページダイアログ

```text
┌──────────────────────────────────────────────┐
│ 新規ページ                                   │
│ ページのパスを入力してください。              │
│ 「/」でディレクトリを区切ります。             │
│                                              │
│ パス [ a/b/                         ]        │
│                                              │
│                    [キャンセル] [作成]        │
└──────────────────────────────────────────────┘
```

- 初期パスは開始位置で変わる。
- パスの検証エラーは入力の近くに出す。
- 作成後は Page へ移動する。

## 履歴パネル

```text
┌──────────────────────────────┐
│ 履歴                    [×]  │
│ ┌──────────────────────────┐ │
│ │ 現在の版を保存           │ │
│ └──────────────────────────┘ │
│ v3  2026-11-04 10:00  [戻す] │
│ v2  2026-11-04 09:00  [戻す] │
│ v1  2026-11-03 18:00  [戻す] │
└──────────────────────────────┘
```

- 履歴は Page の補助パネル。独立した画面にしない。
- 版を選ぶと版プレビューを開く。
- 現在の版を保存は手動 Revision を作る。

## 版プレビュー

```text
┌──────────────────────────────────────────────────────┐
│ v2 に戻す                                       [×]  │
│ 現在の本文をこの版の内容に置き換えます。              │
│ 復元後の内容は新しい版として保存されます。            │
│                                                      │
│ 現在との差分: +12 / -4 行                            │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 差分または本文プレビュー                         │ │
│ └──────────────────────────────────────────────────┘ │
│                          [キャンセル] [この版に戻す]  │
└──────────────────────────────────────────────────────┘
```

- 復元後に Page を再読み込みする。
- 失敗した場合はダイアログ内に理由を出す。

## レイアウトのルール

1. グローバルヘッダーには、ブランド、検索、新規ページ、アカウントだけを置く。
2. ページのパンくず、タイトル、操作はページヘッダーに置く。
3. サイドバーはページ階層のナビゲーション。本文の一覧とは役割を分ける。
4. ページの補助情報は右側のサイドパネルにまとめる。目次とバックリンクは同じパネル。
5. 履歴はページサイドパネルと排他にし、右側の補助領域を切り替える。
6. 検索、新規ページ、削除確認、版プレビューはオーバーレイ。ページ遷移の一部にしない。
7. モバイルでも `+` は常設。サイドバーはオーバーレイで開く。
8. ページ遷移時にサイドバーや本文を開閉するアニメーションをしない（UI 契約で確定）。
9. 初期サイドバー状態は UI 契約で決める。この IA では「デスクトップは開、モバイルは閉」を推奨。
10. 目次、履歴、検索の開閉は State として扱い、開時と閉時で別のナビゲーションを作らない。
