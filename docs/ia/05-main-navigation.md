# 5. メインナビゲーション

## 目的

Zeee のメインナビゲーションの構成を整理し、各項目がどのオブジェクトのどのビューに移動するのか、どこで階層を持つのかを明確にする。

ここでいうメインナビゲーションは、ログイン後に常に使える行き先とグローバル操作を指す。ページ本文、目次、バックリンク、履歴、版プレビューはメインナビゲーションに含めない。

## 全体構成

```text
グローバルヘッダー
├─ Zeee（ブランド） → すべてのページ (/)
├─ 検索 → 検索パレット（⌘K）
├─ 新規ページ → 新規ページダイアログ
└─ アカウント → ログアウト

サイドバー
├─ 最近見たページ（最大 5 件）
│  └─ ページ → /pages/:id
├─ すべてのページ (/)
│  ├─ ディレクトリ A → /?dir=A
│  │  ├─ ディレクトリ A/B → /?dir=A%2FB
│  │  └─ ページ A/C → /pages/:id
│  └─ ページ B → /pages/:id
└─ ゴミ箱 → /trash

ページヘッダー（ページ画面のみ）
├─ パンくず → すべてのページ / ディレクトリ
├─ ページタイトル（表示）
├─ 編集 / 閲覧
├─ 目次・バックリンク
├─ 履歴
└─ ページメニュー → 削除
```

- グローバルヘッダーは「アプリ全体の操作」。
- サイドバーは「ページの探索と移動」。
- ページヘッダーは「現在のページの文脈と操作」。
- この 3 つを混ぜない。

## ナビゲーション項目

| 項目           | 種別           | ラベル                     | 行き先                | 選択状態                                      |
| -------------- | -------------- | -------------------------- | --------------------- | --------------------------------------------- |
| ブランド       | Destination    | Zeee                       | `/`（すべてのページ） | なし                                          |
| 検索           | Action         | 検索                       | 検索パレット          | なし                                          |
| 新規ページ     | Action         | 新規ページ                 | 新規ページダイアログ  | なし                                          |
| 最近見たページ | Shortcut group | 最近見たページ             | 各 Page               | 現在ページに `aria-current="page"`            |
| すべてのページ | Destination    | すべてのページ             | `/`                   | `/` が Page でも Directory でもないとき       |
| ディレクトリ   | Destination    | ディレクトリ名             | `/?dir=...`           | 現在の Directory に `aria-current="location"` |
| ページ         | Destination    | ページ名（末尾セグメント） | `/pages/:id`          | 現在ページに `aria-current="page"`            |
| ゴミ箱         | Destination    | ゴミ箱                     | `/trash`              | ゴミ箱表示中                                  |
| アカウント     | Action         | ユーザー名 / アカウント    | アカウントメニュー    | なし                                          |
| ログアウト     | Action         | ログアウト                 | `/auth/logout`        | なし                                          |

## グローバルヘッダー

| 要素            | 役割                         | 備考                                                                |
| --------------- | ---------------------------- | ------------------------------------------------------------------- |
| ブランド `Zeee` | すべてのページへ戻る         | ページ固有の情報を持たない                                          |
| サイドバー開閉  | サイドバーの表示状態を変える | ナビゲーション項目ではない。State                                   |
| 検索            | 検索パレットを開く           | デスクトップは入力風ボタン、モバイルは検索アイコン。`⌘K` / `Ctrl+K` |
| 新規ページ `+`  | 新規ページダイアログを開く   | モバイルでも常設。深いメニューに隠さない                            |
| アカウント      | ユーザー情報とログアウト     | 独立したプロフィール画面は作らない                                  |

グローバルヘッダーに置かないもの:

- ページのパンくず
- ページタイトル
- 編集 / 履歴 / 目次 / ページメニュー
- ページ固有の保存状態

これらはページヘッダーに置く。

## サイドバー

| 領域 | 内容                   | ルール                                                        |
| ---- | ---------------------- | ------------------------------------------------------------- |
| 上部 | 最近見たページ         | 最大 5 件。0 件ならグループごと隠す。現在ページを強調         |
| 中央 | すべてのページのツリー | ルートは `/` へのリンク。ディレクトリは展開・折りたたみできる |
| 下部 | ゴミ箱                 | 常に表示。現在のナビゲーション状態を `aria-current` で示す    |

- サイドバーのツリーは「ページ階層を辿る場所」。
- 本文側の「すべてのページ」は「更新順の一覧」。同じ Page 集合だが、役割が違う。
- ディレクトリをトップレベルのナビ項目にしない。ツリーとパンくずから辿る。
- `Directories` という独立した一覧ページは作らない。
- `Spaces`、`Root pages`、`Browse` は使わない。

## ページヘッダー

| 要素               | 役割                     | 備考                                                               |
| ------------------ | ------------------------ | ------------------------------------------------------------------ |
| パンくず           | 現在地                   | `すべてのページ / a / b / 現在ページ`。各 Directory は `/?dir=` へ |
| ページタイトル     | 現在ページの表示         | 末尾セグメントを表示。フルパスはツールチップとパンくずで示す       |
| 編集 / 閲覧        | モード切替               | State toggle。ページを移動しない                                   |
| 目次・バックリンク | ページサイドパネルの開閉 | State toggle。ページを移動しない                                   |
| 履歴               | 履歴パネルの開閉         | State toggle。ページを移動しない                                   |
| ページメニュー     | 削除などの補助操作       | 破壊的操作はメニュー内に置く                                       |

ページヘッダーに検索、新規ページ、アカウントを置かない。これらはグローバルヘッダーの役割。

## 新規ページの初期パス

新規ページは常に同じダイアログを使う。ただし、開始位置によって初期パスを変える。

| 開始位置             | 初期パス              | 例         |
| -------------------- | --------------------- | ---------- |
| すべてのページ       | 空                    | ``         |
| ディレクトリ `a/b`   | `a/b/`                | `a/b/`     |
| ページ `a/b/c`       | 親ディレクトリ `a/b/` | `a/b/`     |
| 検索結果なし         | 検索クエリ            | `設計メモ` |
| 未作成の Wiki リンク | リンク先のパス        | `a/b/設計` |
| ゴミ箱               | 空                    | ``         |

- 入力値は常にフルパス。
- 末尾の `/` はエラー。ディレクトリ候補を選んだ場合だけ `/` が入る。
- ページとディレクトリのモード切替は作らない。
- 作成後は Page へ移動する。

## 現在地の示し方

| 状態           | 表現                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| すべてのページ | サイドバーの「すべてのページ」を選択。ブランドは常に有効                       |
| ディレクトリ   | ツリーの該当 Directory を `aria-current="location"`。パンくずの末尾を現在地に  |
| ページ         | ツリーと Recent の該当 Page を `aria-current="page"`。パンくずの末尾を現在地に |
| 検索結果       | 「すべてのページ」のビュー状態として扱う。検索クエリを画面に表示               |
| ゴミ箱         | サイドバー下部の「ゴミ箱」を選択                                               |
| ページがない   | パンくずを出さず、一覧への導線を出す                                           |

- `aria-current="page"` は Page、`aria-current="location"` は Directory に使う。
- パンくずの現在ページはリンクにしない。
- サイドバーのツリーは、現在ページ/ディレクトリの祖先を自動で展開する。
- 展開状態はローカルの UI 状態であり、ナビゲーション履歴や URL の状態にはしない。

## 現状との差分

| 項目                                | 現状                                       | 目標                                  |
| ----------------------------------- | ------------------------------------------ | ------------------------------------- |
| ブランド                            | `/` へ。画面名は「ページ」                 | `/` へ。画面名は「すべてのページ」    |
| グローバルヘッダー                  | パンくずとページ名を表示                   | ブランド・検索・新規・アカウントだけ  |
| サイドバー「すべてのページ」        | グループラベル                             | ルートへのリンク + ツリー             |
| サイドバー「最近見たページ」        | 最大 5 件                                  | 維持                                  |
| ゴミ箱                              | サイドバー下部                             | 維持                                  |
| 検索                                | ヘッダー、モバイルの検索フォーム、結果一覧 | グローバルヘッダー + 結果一覧に一本化 |
| 新規ページ                          | 常に空のパス                               | 文脈に応じた初期パス                  |
| ページヘッダー                      | ページ名と操作が本文側                     | パンくず・タイトル・操作をまとめる    |
| アカウント                          | 名前とログアウトを並べる                   | アカウントメニューにまとめる          |
| Home / Spaces / Browse / Root pages | なし、または過去の提案                     | 使わない                              |

## ナビゲーションに含めないもの

| 名前                         | 理由                                           |
| ---------------------------- | ---------------------------------------------- |
| 目次                         | Page の補助ビュー。ページ内のアンカー移動      |
| バックリンク                 | Page の補足情報。Page 間の参照                 |
| 履歴                         | Page の補助パネル。独立した行き先ではない      |
| 版プレビュー                 | Revision の確認。履歴から開くオーバーレイ      |
| 検索結果                     | 検索パレットの結果、または `/?q=` のビュー状態 |
| 新規ページダイアログ         | アクション。行き先ではない                     |
| 削除確認 / 完全削除確認      | アクション。行き先ではない                     |
| ページメニュー               | ページ固有の操作。メインナビではない           |
| アカウントのプロフィール画面 | 作らない。メニュー内のログアウトだけ           |

## ナビゲーションの検証

| ユーザーの流れ                       | 入口                           | 到達できるか                             |
| ------------------------------------ | ------------------------------ | ---------------------------------------- |
| 既知のページを検索で開く             | グローバルヘッダーの検索、`⌘K` | 検索パレット → Page                      |
| 最近見たページから戻る               | サイドバーの Recent            | Page                                     |
| ページツリーからディレクトリを辿る   | サイドバーの「すべてのページ」 | Directory → Page                         |
| ページを読み、目次・リンクを辿る     | Page                           | Page 内の目次、Wiki リンク、バックリンク |
| ディレクトリを指定してページを作る   | ディレクトリ画面の `+`         | 新規ページ（`dir/`） → Page              |
| ページを編集し、自動保存する         | Page の編集                    | Page 内で完了                            |
| ページのパスを変える                 | Page の編集                    | Page 内で完了                            |
| 履歴を見て前の版に戻す               | Page の履歴                    | 履歴 → 版プレビュー → Page               |
| ページを削除し、ゴミ箱から復元する   | Page メニュー                  | 削除 → ゴミ箱 → Page                     |
| 未作成の Wiki リンクからページを作る | Page 内の未作成リンク          | 新規ページ → Page                        |
